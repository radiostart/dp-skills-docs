    doc-metrics.py¶

    dp-skills doc-metrics — 문서 묶음의 정량 지표를 결정론적으로 잰다 (읽기 전용).

    bench 사이클 (tools/bench-cycle.py) 의 정량 지표 층이다. 블라인드 채점 (@ag-bench-scorer) 이 「읽히나·행동할 수 있나」를 사람 눈으로 보고, 이 도구는 「길이·밀도·중복」을 숫자로 본다. 둘을 섞지 않는다 — 채점자는 이 결과를 보지 않고, 전후 대조 (compare) 가 두 층을 나란히 놓는다.

    지표 (프런트매터는 뺀다 · 글자 수는 Python len): chars 본문 글자 수 lines 본문 줄 수 avg_sentence 마침표·물음표·느낌표·줄 끝으로 자른 문장의 평균 글자 수 (빈 문장 제외) id_density 1,000자당 식별자 수 — #14 · C3 · r2 · QAPRJ-5394 · F-1 꼴 paren_dot_density 1,000자당 괄호 쌍 + 가운뎃점 (·) 수 paren_ratio 바깥 괄호 안 글자 ÷ 본문 글자 (중첩은 바깥 하나로 센다) history_ratio 날짜 (2026-..-..) · 회차 · 라운드 · r{N} 이 든 줄 ÷ 전체 줄 — critic 이력 비대가 바로 이 지표 dup_ratio 20자 이상 같은 문장이 묶음의 다른 파일에도 있는 문장 ÷ 전체 문장 (파일 하나면 0) UTF-8 로 읽히지 않는 파일은 skipped 에 적고 재지 않는다 · 없는 파일은 missing.

    린트 묶음 (lint_bundle) — 표본 유형에 맞는 기존 결정론 도구를 --json 으로 돌려 요약만 붙인다 (같은 것을 LLM 채점으로 다시 재지 않기 위한 자리): plan → plan-validate (--mode standard · valid · warnings 수 · errors 수) · handoff-quality (summary) critic → critic-lint (pass · violations 수) eval → verify-report-lint (pass · violations 수) 유형은 파일명으로 가른다 — .plan.critic[.rN].md → critic · .eval[.rN].md → eval · .plan[.rN].md → plan. 도구가 없거나 JSON 을 못 내면 error 로 적고 계속한다 (참고 지표 — 사이클을 막지 않는다).

    Usage: python3 doc-metrics.py FILE [FILE …] [--root DIR] [--md] [--lint] (모듈) measure(root, rels) -> dict · lint_bundle(path) -> dict · kind_of(path) -> str | None

    Exit: 0 — 쟀다 · 1 — 하나도 못 쟀다 (없음·건너뜀) · 2 — 사용 오류
